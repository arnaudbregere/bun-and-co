## 2. Ce qui a été livré

### Socle technique

Nuxt 4.7 en génération statique, TypeScript strict complété par
`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride` et
`noFallthroughCasesInSwitch`.

ESLint avec les règles d'accessibilité du balisage, Prettier, Vitest, Playwright avec
axe-core, et un pipeline qui exécute tout cela à chaque demande de fusion.

### Domaine métier

| Module | Rôle |
| --- | --- |
| `types.ts` | vocabulaire, identifiants nominaux |
| `money.ts` | montants en centimes entiers, arithmétique protégée |
| `menu-rules.ts` | forfaits de taille, substitutions autorisées |
| `pricing.ts` | prix d'une ligne, total du panier |
| `cart.ts` | ajout, regroupement, quantités, limites |
| `order.ts` | numéro de commande, confirmation |
| `catalogue.ts` | consultation pure |
| `ports.ts` | contrats avec l'extérieur |
| `errors.ts` | erreurs du domaine |

### Services

Les vingt-sept références de la carte, le catalogue statique derrière son port, et la
persistance de la commande en cours sur un stockage injecté.

## 3. Décisions prises pendant la session

| Décision | Raison |
| --- | --- |
| Node porté à 22.23.4 | Nuxt 4.7 refuse Node 20 |
| pnpm épinglé en 10.34.9 | corepack 0.33 ne sait lancer ni pnpm 11 ni pnpm 12 |
| Route Nitro préconstruite plutôt que serveur Node | vrai code d'API, aucun processus à l'exécution, compatible GitHub Pages |
| Constitution amendée en 1.1.0 | le principe III interdisait toute route Nitro, ce qui confondait serveur vivant et route préconstruite |
| Montants en centimes entiers, type nominal | une confusion euros et centimes est silencieuse |
| `ProductId` et `CartLineId` marqués, `ExtraId` et `RemovableId` non | on marque ce qui se confond silencieusement, pas tout ce qui a le même type de base |
| Frontières d'architecture appliquées par ESLint | une architecture tenue par la seule bonne volonté se dégrade au premier coup de pression |
| Identité d'une ligne de panier calculée depuis son contenu | regroupement immédiat, aucun générateur, tests déterministes |
| Numéro de commande séquentiel | le client comprend l'ordre d'appel, et la fonction reste pure |
| Noms de code en anglais, prose en français | convention professionnelle, appliquée tant que le coût reste nul |
| Polices Archivo et Petrona | Inter et Fraunces signalées comme omniprésentes par le détecteur de design |
| Le Mariner ajouté à la carte | couvre l'allergène poissons, absent des vingt-six autres références |

## 5. Décisions ouvertes

1. **Fond crème et règle `cream-palette`.** Le détecteur de design reproche le blanc cassé
   chaud comme surface par défaut des interfaces générées. La règle est désactivée et
   l'écart justifié dans `DESIGN.md`. L'alternative, un fond teinté de vert olive, sort de
   la direction retenue et imposerait de revérifier toutes les paires de contraste.
2. **Couverture à 100 % sur les services.** Tenable aujourd'hui. Si elle force un jour un
   test absurde, c'est le seuil qu'il faut baisser, pas le test qu'il faut écrire.
3. **`OrderGateway`.** Réintroduit le jour où une caisse ou une cuisine reçoit la commande.
   Hors périmètre de la version 1.
